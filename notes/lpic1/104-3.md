# Control Mounting and Unmounting File Systems

## Mounting and Unmounting

When we have a formatted partition we should be able to mount it, so it could be
accessible in the linux file system hierarchy.

```bash
# You can omit -t and let the command decide itself.
sudo mount /dev/sda1 /media/ali/backups -t ext 4

# Run mount with no arguments to print out all the mountpoints.
sudo mount | grep /dev/sda1
/dev/sda1 on /media/ali/backup type ext4 (rw,realtime)
```

Now all files in the `/dev/sda1` are accessible from `/media/ali/backup`.

To unmount, simply use the `umount` command with the block device path or the directory.
These two are equivalents considering the above mounting.

```bash
sudo umount /dev/sda1
sudo umount /media/ali/backup
```

> Swap disks doesn't need mounting. You should just swapon and swapoff.

```bash
mount -t ext4 /dev/sda1 /media/ali/backup  # -t indicates the type of filesystem.

mount -o remount,ro /dev/sda1  # -o passes some options.
```

`/media` and `/mnt` directories are used for mounting, but you can use any directories.
But when you should use /media and when /mnt:

- `/media`: For removable disks and temporary mounts.
- `/mnt`: For permanent mounts.

### UUIDs and LABELs

You already know the issues with sda type namings. They change! Therefore, you should
use UUIDs. Check them with -O options in `lsblk` or using `lsblk -o +UUID`, or you can
use `blkid`.

## fstab

For automatic mounting Linux uses the `/etc/fstab` file. It is like a table that tells
the kernel what filesystem should be mounted during the boot.

```txt
# /etc/fstab: static file system information.
#
# Use 'blkid' to print the universally unique identifier for a
# device; this may be used with UUID= as a more robust way to name devices
# that works even if disks are added and removed. See fstab(5).
#
# <file system> <mount point>   <type>  <options>       <dump>  <pass>
# / was on /dev/nvme0n1p2 during installation
UUID=158c794e-fea3-4653-89d8-9e6a89c0c955 /               ext4    errors=remount-ro 0  1
# /boot/efi was on /dev/nvme0n1p1 during installation
UUID=43A6-0FD0  /boot/efi       vfat    umask=0077      0       1
/swapfile                                 none            swap    sw              0    0
```

### Some Tips

- `noatime` will disable recording of the access time. It may improve performance.
- User-mounted filesystems default to noexec unless exec is specified after user.

## Systemd Mount Units

When using systemd, a unit configuration file whose name ends in `.mount` encodes
information about a file system mountpoint controlled and supervised by systemd.

```bash
sudo systemctl list-units --type=mount
[sudo] password for ali:
Sorry, try again.
[sudo] password for ali:
  UNIT                                                 LOAD   ACTIVE SUB     DESCRIPTION
  -.mount                                              loaded active mounted Root Mount
● boot-efi.mount

ali@ideapad:~ $ sudo systemctl cat sys-fs-fuse-connections.mount
# /lib/systemd/system/sys-fs-fuse-connections.mount
#  SPDX-License-Identifier: LGPL-2.1-or-later
#
#  This file is part of systemd.
#
#  systemd is free software; you can redistribute it and/or modify it
#  under the terms of the GNU Lesser General Public License as published by
#  the Free Software Foundation; either version 2.1 of the License, or
#  (at your option) any later version.

[Unit]
Description=FUSE Control File System
Documentation=https://www.kernel.org/doc/Documentation/filesystems/fuse.txt
Documentation=https://www.freedesktop.org/wiki/Software/systemd/APIFileSystems
DefaultDependencies=no
ConditionPathExists=/sys/fs/fuse/connections
ConditionCapability=CAP_SYS_ADMIN
ConditionVirtualization=!private-users
Before=sysinit.target

# These dependencies are used to make certain that the module is fully
# loaded. Indeed udev starts this unit when it receives an uevent for the
# module but the kernel sends it too early, ie before the init() of the module
# is fully operational and /sys/fs/fuse/connections is created, see issue#17586.

After=modprobe@fuse.service
Requires=modprobe@fuse.service

[Mount]
What=fusectl
Where=/sys/fs/fuse/connections
Type=fusectl
Options=nosuid,nodev,noexec
```
