# Wireless Network Topology

All of those logical topologies we talked about in the previous lesson are still gonna
apply to our wireless networks, but when we talked about physical perspective, wireless
add two different modes that we need to understand.

## Infrastructure Mode

It is the most common type in wireless networks. In fact, it is the one you have used to
watch the network+ videos.

When I am at home and I have wireless network in the house and it connects to an outside
provider through the cable and fiber modem you are using the infrastructure mode.

The infrastructure mode uses a wireless network that uses a wireless access point as a
centralized point. :question:.

You use it as you would use star topology in a wired network, but wireless.

## Ad Hoc Mode

It is decentralized. It creates peer-to-peer connections and does not require a router
or access point. :question:.

There is no router or centralized connection point, instead I connect my laptop to your
laptop and we can make that routing decisions and the fly. This allow the people to jump
in and jump out of the network as much as they want.

## Wireless Mesh Topology

It is an interconnection of different types of nodes, devices, and radios. If we have
all these routers and gateways and servers and radio antennas, we gonna mesh them all
together and create this unique network, so we can use different radio frequencies like
bluetooth, wifi, microwave, satellite, and cellular.
