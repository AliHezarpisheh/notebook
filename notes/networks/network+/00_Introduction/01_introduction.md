# Introduction

This course is considered the first networking certification for entering the networking
or cybersecurity industry. It gives you the foundation and baseline knowledge of
networking. Through out this course we are going to learn how to configure, manage, and
troubleshoot network infrastructures.

> CompTIA A+ knowledge is assumed here.

There are five main domains in this course:

- **Network concepts**
- **Network implementations**
- **Network operations**
- **Network Security**
- **Network troubleshooting**
