# Manage Printers and Printing

## CUPS

Common Unix Printing System(CUPS) is the main service used for managing printers and
printing.

```bash
ali> sudo apt install cups
...

ali> sudo systemctl status cups
● cups.service - CUPS Scheduler
     Loaded: loaded (/lib/systemd/system/cups.service; enabled; vendor preset: enabled)
     Active: active (running) since Fri 2026-02-20 09:28:29 +0330; 5h 26min ago
TriggeredBy: ● cups.socket
             ● cups.path
       Docs: man:cupsd(8)
   Main PID: 126973 (cupsd)
     Status: "Scheduler is running..."
      Tasks: 1 (limit: 18721)
     Memory: 4.1M
        CPU: 132ms
     CGroup: /system.slice/cups.service
             └─126973 /usr/sbin/cupsd -l

Feb 20 09:28:29 ideapad systemd[1]: Starting CUPS Scheduler...
Feb 20 09:28:29 ideapad systemd[1]: Started CUPS Scheduler
```

Its configuration files are under `/etc/cups/` directory. The configuration file for
cups daemon is at `/etc/cups/cupsd.conf`. Change it base on your requirements. You can
access cups by a web UI(most common way), a GUI, or cli. The web ui is on port 631 by
default.

> All the printers data is saved at `/etc/cups/printers.conf`. Do not edit it manually.

cups logs are at `/var/log/cups`.

> cups will install most printer drivers with itself.

By default, the system users can only view printers and queue jobs, and they can not add
printers or delete them. You can change this rule in the `cupsd.conf` file.

```txt
<Limit CUPS-Add-Modify-Printer CUPS-Delete-Printer CUPS-Set-Default>
    AuthType Default
    Require user @printer_admin
    Order deny,allow
</Limit>
```

The above examples configure cups as it let users in `printer_admin` group add, modify,
delete, and set default printers.

## Legacy Tools

`lpq` and its related commands was the main tool for managing printers before. `cups`
support these legacy commands. You should install `cups-bsd` to make the legacy commands
work.

### lpq

Use it to list the printer(s) queue. Use `-a` for listing all queues, or `-P` with a
printer's name to list its queue.

```bash
ali> lpq -PApple-Dot-Matrix
Apple-Dot-Matrix is ready and printing
Rank    Owner   Job     File(s)                         Total Size
active  unknown 1       unknown                         7168 bytes
1st     unknown 2       unknown                         2048 bytes
```

### lpr

Use it to print files. This command send jobs to the printer.

```bash
ali> lpr -PApple-Dot-Matrix /tmp/essay.txt
```

> If no printer specified, the default printer will be used.

### lprm

Use it to remove files jobs from printer queue.

```bash
ali> lpq
Apple-Dot-Matrix is ready and printing
Rank    Owner   Job     File(s)                         Total Size
active  ali    1       Untitled Document 1             7168 bytes
1st     ali    2       Untitled1                       2048 bytes
2nd     ali    3       for_print.txt                   1024 bytes

ali> lprm 2
ali> lpq
Apple-Dot-Matrix is ready and printing
Rank    Owner   Job     File(s)                         Total Size
active  ali    1       Untitled Document 1             7168 bytes
1st     ali    3       for_print.txt                   1024 bytes
```

> Only root can remove other people jobs.

`lprm -` will remove all printing jobs and `lprm -Phi -` will remove the jobs for `hi`
printer.

### lpc

Controls and troubleshoot printers.

```bash
ali> lpc status
Apple-Dot-Matrix:
    printer is on device 'ipp' speed -1
    queuing is enabled
    printing is enabled
    2 entries
    daemon present
```

- `queuing is enabled` means the printer accept new jobs for printing. Disabling it
  means it won't accept new printing jobs.
- `printing is enabled` means that the printer will print the queued jobs until they are
  all printed or the printing goes disabled.

There are commands to modify these states:

| Command     | Usage                                            |
| ----------- | ------------------------------------------------ |
| cupsaccept  | Tells the printer queue to accept new jobs       |
| cupsreject  | Tells the printer to reject any new job          |
| cupsenable  | Enables the actual/physical printing of the jobs |
| cupsdisable | Disables the physical printing of the jobs       |

In all cases you should specify the printer name, with an additional switch, `-r`, which
you can provide reason with it.

```bash
ali> cupsdisable Apple-Dot-Matrix -r "need more paper"
ali> lpc status
Apple-Dot-Matrix:
    printer is on device 'ipp' speed -1
    queuing is enabled
    printing is disabled
    2 entries
    daemon present
```
