# Mail Transfer Agent (MTA) Basics

## MTAs

Email is an integral part of many Linux systems. Each user has its own mailbox and can
receive and send mails to other users. This is done via Mail Transfer Agents(MTAs).

### sendmail

Legacy tool. One of the oldest MTAs. It is not security-oriented but other tools such as
postfix has a compatible interface for it.

### exim

It aims to be general and flexible, with extensive facilities for checking incoming
e-mails.

### postfix

The defacto of the MTAs? The alternative to `sendmail`.

> You may should install `postfix`, `mailx`, `bsd-mailx`, or `mailutils` on your system.

#### sendmail Emulation Layer

As I said before, `postfix` implemented the `sendmail` interface. So you can use the
`sendmail` commands, regardless of the MTA.

### Aliases

There are some mail aliases on the system at `/etc/aliases`. It map the local system
usernames to different email addresses, multiple users, files, or programs.

```bash
ali> cat /etc/aliases
#
#  Aliases in this file will NOT be expanded in the header from
#  Mail, but WILL be visible over networks or from /bin/mail.
#
#       >>>>>>>>>>      The program "newaliases" must be run after
#       >> NOTE >>      this file is updated for any changes to
#       >>>>>>>>>>      show through to sendmail.
#

# Basic system aliases -- these MUST be present.
mailer-daemon:  postmaster
postmaster:     root

# General redirection for pseudo accounts.
bin:            root
daemon:         root
adm:            root
lp:             root
sync:           root
shutdown:       root
halt:           root
mail:           root
news:           root
uucp:           root
operator:       root
games:          root
www:            webmaster
webmaster:      root
```

In case of change, you should execute `newaliases`.

## Local Forwards

Each user can create a `.forward` and put an address in it, so all mails for the user
will be forwarded to that address.

> Also, you can send an email using the method:
> `echo -e "email content" | mail -s "email subject" "example@example.com"`

## mailq

This command will list all the emails in the mail queue of the system. It will show the
error of an unsent email.
