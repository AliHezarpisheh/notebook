# Localization and Internationalization

## Timezone

We have timezones because the Sun is in different places at the sky in different cities
and countries. Time zones are created for us, that basic daily events happen at the same
time for all of us.

In the Linux and CS context, there are multiple reasons why the OS should know our
timezone:

- It need to know the timezone to run tasks on needed times.
- We want to see our date and time on our system:)!

There is a `date` command with a `+` operator for formatting the datetime:

```bash
ali> date
Fri Feb  6 11:20:42 AM +0330 2026

ali> date +'%Y-%m-%d'
2026-02-06

ali> date +'%Y-%m-%d %H:%M:%S'
2026-02-06 11:44:29
```

Also there is a controller command:

```bash
ali> timedatectl
               Local time: Fri 2026-02-06 11:46:25 +0330
           Universal time: Fri 2026-02-06 08:16:25 UTC
                 RTC time: Fri 2026-02-06 08:16:25
                Time zone: Asia/Tehran (+0330, +0330)
System clock synchronized: yes
              NTP service: active
          RTC in local TZ: no
ali> timedatectl show
Timezone=Asia/Tehran
LocalRTC=no
CanNTP=yes
NTP=yes
NTPSynchronized=yes
TimeUSec=Fri 2026-02-06 11:46:30 +0330
RTCTimeUSec=Fri 2026-02-06 11:46:30 +0330
```

There are binary files for time zones at `/usr/share/zoneinfo/`. There is also a file at
`/etc/localtime` which is a link to the one of the binary files in `zoneinfo/` folder.

```bash
ali(/usr/share/zoneinfo)> ls
Africa      Asia       Canada   Cuba   EST ...

ali> ls -lrth /etc/localtime
lrwxrwxrwx 1 root root 31 Oct 23 17:15 /etc/localtime -> /usr/share/zoneinfo/Asia/Tehran
```

### How to Change the Timezone Configuration

There are multiple ways for doing it. There was a `tzconfig` command that is deprecated
and now you should do another commands you can see below:

```bash
ali> dpkg-reconfigure tzdata

ali> tzselect

ali> env TZ="Asia/Tokyo" date
Fri Feb  6 05:21:59 PM JST 2026
```

## Languages

```bash
ali> locale
LANG=en_US.UTF-8
LANGUAGE=
LC_CTYPE="en_US.UTF-8"
LC_NUMERIC=az_IR
LC_TIME=en_US.UTF-8
LC_COLLATE="en_US.UTF-8"
LC_MONETARY=az_IR
LC_MESSAGES="en_US.UTF-8"
LC_PAPER=az_IR
LC_NAME=az_IR
LC_ADDRESS=az_IR
LC_TELEPHONE=az_IR
LC_MEASUREMENT=az_IR
LC_IDENTIFICATION=az_IR
LC_ALL=
```

These variables tell the system which standard they should use for specific
requirements. For example, The time is shown with the `en_US.UTF-8` format. I don't want
Iran standards on my system so let's change them.

> By the way, the `LC_ALL` can be used to change all the settings and set a unified
> standard.

```bash
ali> vi /etc/default/locale
ali> cat /etc/default/locale
LANG=en_US.UTF-8
LC_NUMERIC=en_US.UTF-8
LC_TIME=en_US.UTF-8
LC_MONETARY=en_US.UTF-8
LC_PAPER=en_US.UTF-8
LC_NAME=en_US.UTF-8
LC_ADDRESS=en_US.UTF-8
LC_TELEPHONE=en_US.UTF-8
LC_MEASUREMENT=en_US.UTF-8
LC_IDENTIFICATION=en_US.UTF-8

ali> update-locale && source /etc/default/locale # Or reboot
ali> locale
LANG=en_US.UTF-8
LANGUAGE=
```

### LANG=C

A lot of scripts have `LANG=C` at top of them, preventing unexpected issues related to
languages, characters, and orderings, ensuring that these attributes are going to work
as expected.

## Character Encodings

At the bottom of computers, there are only `0 and 1`s. You already know it, but how can
we display characters? By associating numbers to characters For example I will create a
character encoding format or standard, saying that `a` is presented by `1`. I give every
character up to 4 bytes, so the `a` should be like `00000001` on the first byte, and the
other bytes are not used.

This is a simple demonstration of what is happening in character encoding world. Let's
see the most used character encoding formats:

### ASCII

Use 7 bits and supports 128 characters, which is not enough in some situations.

### ISO-8859

Support more characters than `ASCII`.

### UTF-8

The defacto of encoding methods. It is the acronym of `Unicode Transformation Format`.
It supports all written languages and also some special characters. It is compatible
with `ASCII` too.

Use `iconv` command to switch the encoding format of text files.

```bash
iconv -f WINDOWS-1258 -t UTF-8 /tmp/myfile.txt
```
